# HOW TO: Set Runway Positions on a Background

A step-by-step guide for new developers on how to author runway positions for a level background.

## Overview

Runways are positioned on the **master background image** using pixel coordinates. At runtime, the game converts these to world-space positions independently for every aspect-ratio variant, so the runway stays correctly aligned on any screen size.

## Key Concepts

### Master Image

The raw source image at `raw_assets/level-N-master.png`. This is the **only** image where you manually pick pixel positions. All other ratio variants are auto-generated by `pnpm build:levels`.

### Two-Endpoint Form (current — required)

Each runway is defined by **two threshold endpoints** in master-image pixels:

- `masterX1`, `masterY1` — first threshold (start of the runway strip)
- `masterX2`, `masterY2` — second threshold (end of the runway strip)
- `masterWidth` — the runway's short-axis width, measured in master pixels

The game derives `centerX`, `centerY`, `length`, and `direction` from these two points at runtime. Do **not** precompute center/length/direction yourself.

### Why two points, not one?

The background is stretched with different X and Y scale factors per ratio (non-uniform). A single point + precomputed length/angle only works on the ratio it was measured on. Two endpoints produce correct results on every ratio.

## Step-by-Step Guide

### 1. Build the level backgrounds

Before you can measure anything, generate the ratio variants:

```bash
pnpm build:levels
```

This creates the output PNGs in `packages/app/src/assets/backgrounds/` (e.g. `16x9/level-4.png`).

### 2. Open the 16x9 output image

Open `packages/app/src/assets/backgrounds/16x9/level-N.png` in any image editor.

### 3. Pick the two threshold endpoints

Click the **start** and **end** of the runway strip (in the landing direction). Note both pixel coordinates:

- Point 1: `(x1, y1)` — the threshold where planes begin their approach
- Point 2: `(x2, y2)` — the opposite threshold

### 4. Convert to master-image coordinates

Run the `runway` command:

```bash
pnpm runway runway <levelNumber> 16x9 <runwayId> <x1> <y1> <x2> <y2>
```

Example:

```bash
pnpm runway runway 4 16x9 level4-rw06 1150 600 1420 625
```

**Output:**

- `masterX1`, `masterY1` — first endpoint in master-image pixels
- `masterX2`, `masterY2` — second endpoint in master-image pixels

The command also checks if this runway ID already exists in `levels.config.ts` and shows the current values for diffing.

### 5. Measure the runway width (optional but recommended)

Pick two points across the **short axis** (the narrow width of the runway) on any ratio image:

```bash
pnpm runway size 4 16x9 1150 600 1150 640
```

Or pass the width points as extra args to the `runway` command (11 args total):

```bash
pnpm runway runway 4 16x9 level4-rw06 1150 600 1420 625 1150 560 1420 605
```

**Output:** `masterWidth` — the runway width in master-image pixels.

### 6. Sanity-check the positions

Verify both endpoints land correctly on every generated ratio:

```bash
pnpm runway verify 4 <masterX1> <masterY1>
pnpm runway verify 4 <masterX2> <masterY2>
```

Each prints the projected pixel position on every ratio's image. Open each ratio's PNG and confirm the points land on the runway threshold ends. An "OUT OF FRAME" result means that ratio's crop does not include this part of the master image — check `mobileZoom`/`mobileRatios` in `process-backgrounds.config.json`.

### 7. Add to `levels.config.ts`

Paste the values into the runway entry:

```ts
{
  id: 'level4-rw06',
  rwNumber: '06',
  oppositeRwNumber: '24',
  masterX1: 2875,
  masterY1: 1650,
  masterX2: 3550,
  masterY2: 1713,
  masterWidth: 678,
  allowedColors: ['blue', 'green', 'violet'],
}
```

**Important:** Do **not** include `centerX`, `centerY`, `direction`, `length`, or `width` when using the two-endpoint form — the game derives those automatically. Remove any legacy `masterX`/`masterY`/`masterLength`/`positionOverrides` fields.

### 8. Test

```bash
pnpm dev
```

Toggle the debug overlay in-game to confirm collision circles align with the painted runways on all aspect ratios.

## Common Mistakes

| Mistake                                                            | Why it is wrong                                       | Fix                                                 |
| ------------------------------------------------------------------ | ----------------------------------------------------- | --------------------------------------------------- |
| Using `centerX`/`centerY` fractions instead of `masterX1/Y1/X2/Y2` | Only accurate on 16x9, drifts on other ratios         | Use `pnpm runway runway` to get master pixel coords |
| Measuring length/direction manually                                | Non-uniform scaling makes per-ratio measurement wrong | Let the game derive these from the two endpoints    |
| Using only one endpoint                                            | Cannot correct for non-uniform stretch                | Always use two threshold points                     |
| Forgetting `masterWidth`                                           | Runway appears too narrow or wide on non-16x9 ratios  | Measure with `pnpm runway size`                     |
| Editing the generated ratio PNGs directly                          | Regenerated by `pnpm build:levels` — edits are lost   | Edit the master image or the config only            |

## CLI Quick Reference

| Command                                                                               | Purpose                                      |
| ------------------------------------------------------------------------------------- | -------------------------------------------- |
| `pnpm runway runway <level> <ratio> <id> <x1> <y1> <x2> <y2>`                         | Two endpoints → masterX1/Y1/X2/Y2            |
| `pnpm runway runway <level> <ratio> <id> <x1> <y1> <x2> <y2> <wx1> <wy1> <wx2> <wy2>` | Same + compute masterWidth from width points |
| `pnpm runway size <level> <ratio> <x1> <y1> <x2> <y2>`                                | Measure width → masterWidth                  |
| `pnpm runway pick <level> <ratio> <pixelX> <pixelY>`                                  | Single point → masterX/masterY (legacy)      |
| `pnpm runway measure <level> <ratio> <x1> <y1> <x2> <y2>`                             | Distance → masterLength (legacy)             |
| `pnpm runway verify <level> <masterX> <masterY>`                                      | Project a point on every ratio image         |
